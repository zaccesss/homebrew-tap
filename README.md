# Homebrew tap

Homebrew formulae for my command line tools. Install with:

```sh
brew install zaccesss/tap/footprints
```

Each formula installs the built binary for the machine from the matching GitHub release and checks it against the recorded checksum. The formulae are filled from [zaccesss/footprints](https://github.com/zaccesss/footprints) at each release.
